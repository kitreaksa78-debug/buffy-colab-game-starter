Buffy · Colab Game Starter

បន្ទាត់តែមួយសម្រាប់ Google Colab ឬ Kaggle — បើកហ្គេម HTML5/WASM ហើយបោះ link ឲ្យលេងក្នុង browser។

១. បញ្ជាតែមួយបន្ទាត់

!curl -fsSL …/buffy-start.sh | sh

បើ zip ហ្គេមនៅក្នុង /content រួចហើយ — រត់ត្រឹមនេះគ្រប់គ្រាន់។

២. បើហ្គេមមាន link ទាញយកផ្ទាល់

!curl -fsSL …/buffy-start.sh \
  | GAME_URL="https://…/game.zip" sh

⚠️ ហ្គេមត្រូវជា browser game

zip ត្រូវមាន index.html (ដូចហ្គេម itch.io ដែលមានប៊ូតុង “Run in browser”)។ ហ្គេម PC (.exe, Windows/DirectX, 10+ GB) ដូចជា Sleeping Dogs, GTA V លេងក្នុង browser មិនបានទេ។

ជម្រើសបន្ថែម

  • GAME_ZIP=/content/mygame.zip — ប្រើ zip ក្នុងម៉ាស៊ីន
  • COI=1 — បើក COOP/COEP សម្រាប់ហ្គេមដែលត្រូវការ SharedArrayBuffer
  • TUNNEL=pinggy ឬ lhr — ជ្រើស tunnel ជាក់លាក់
  • PORT=8000, SKIP_TUNNEL=1, STOP=1 (បិទ server)
